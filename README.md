# Facebook Comment Counter

เครื่องมือสำหรับวางข้อความคอมเมนต์ที่คัดลอกจาก Facebook แล้วดึงรายชื่อผู้ร่วมกิจกรรม พร้อมวงล้อสุ่มรายชื่อ

[เปิดใช้งานเว็บ](https://donjai-service.github.io/facebook-comment-counter/)

## วงล้อสุ่ม

- กด `นำรายชื่อไปวงล้อ` จากผลวิเคราะห์ หรือเปิดแท็บวงล้อแล้ววางรายชื่อ 1 คนต่อบรรทัด
- เลือกชุดสี ปรับสีแต่ละช่องและสีชื่อ อัปโหลดโลโก้กลางวงล้อหรือรูปพื้นหลัง (PNG/JPG/WebP ไม่เกิน 10 MB)
- ปรับเวลาหมุน เปิดเต็มหน้าจอ และเลือกนำผู้ชนะออกอัตโนมัติ
- ประวัติผู้ชนะดาวน์โหลดเป็นข้อความได้ ข้อมูลและรูปอยู่ในหน้านี้เท่านั้น รีเฟรชแล้วจะหาย
- แต่ละบรรทัดมีโอกาสเท่ากัน ถ้าไม่ต้องการสิทธิ์ซ้ำให้กดตัดชื่อซ้ำก่อนหมุน
- วงล้อใช้ Spin Wheel 5.0.2 (MIT), ดู SPIN-WHEEL-LICENSE.md; เลือกผลด้วย Web Crypto แบบ rejection sampling

## วิธีใช้

1. เปิด `index.html`
2. วางข้อความคอมเมนต์จาก Facebook ในช่องข้อความ
3. กด `วิเคราะห์รายชื่อ`
4. กด `คัดลอกรายชื่อ` หรือ `ดาวน์โหลด .txt`

## หมายเหตุ

- เครื่องมือนี้ไม่ดึงข้อมูลจาก URL โดยตรง เพราะ Facebook จำกัดการเข้าถึงคอมเมนต์จากหน้าเว็บและสิทธิ์บัญชี
- ถ้าไม่อยากกำหนดคำตอบ ให้เว้นช่อง `คำที่ถือว่าเป็นคำตอบ` ว่างไว้ หรือเอาเครื่องหมายถูกออกจาก `ตัดรายการที่ไม่มีคำตอบตามคำด้านบน`
- โปรแกรมจะข้ามบรรทัดรบกวน เช่น `ความคิดเห็น`, `ดูคำแปล`, `ดูภาษาต้นฉบับ`, `แก้ไขแล้ว`

## GitHub Pages

ถ้าจะเปิดเป็นเว็บผ่าน GitHub Pages:

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ `index.html` และ `README.md`
3. ไปที่ `Settings` > `Pages`
4. เลือก deploy จาก branch หลัก เช่น `main` และ folder `/root`
