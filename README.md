# Facebook Comment Counter

เครื่องมือแบบหน้าเว็บไฟล์เดียว สำหรับวางข้อความคอมเมนต์ที่คัดลอกจาก Facebook แล้วดึงรายชื่อผู้ร่วมกิจกรรมออกมา

## วิธีใช้

1. เปิด `index.html`
2. วางข้อความคอมเมนต์จาก Facebook ในช่องข้อความ
3. กด `วิเคราะห์รายชื่อ`
4. กด `คัดลอกรายชื่อ` หรือ `ดาวน์โหลด .txt`

## หมายเหตุ

- เครื่องมือนี้ไม่ดึงข้อมูลจาก URL โดยตรง เพราะ Facebook จำกัดการเข้าถึงคอมเมนต์จากหน้าเว็บและสิทธิ์บัญชี
- ถ้าไม่อยากกำหนดคำตอบ ให้เว้นช่อง `คำที่ถือว่าเป็นคำตอบ` ว่างไว้ หรือเอาเครื่องหมายถูกออกจาก `ตัดรายการที่ไม่มีคำตอบตามคำด้านบน`
- โปรแกรมจะข้ามบรรทัดรบกวน เช่น `ความคิดเห็น`, `ดูคำแปล`, `ดูภาษาต้นฉบับ`, `แก้ไขแล้ว`

## GitHub Pages

ถ้าจะเปิดเป็นเว็บผ่าน GitHub Pages:

1. สร้าง repository ใหม่บน GitHub
2. อัปโหลดไฟล์ `index.html` และ `README.md`
3. ไปที่ `Settings` > `Pages`
4. เลือก deploy จาก branch หลัก เช่น `main` และ folder `/root`
